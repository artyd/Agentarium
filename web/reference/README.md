# Design reference (source of truth)

These are the original Claude Design prototype files. **Do not edit** — they are the
frozen visual spec ("1-to-1" rule). The production React app in `web/src` must match
them pixel-for-pixel.

- `ag-icons.js` — 36 inline Font Awesome Free 6.7.2 solid icons (`window.AG_ICONS`),
  ported verbatim to `web/src/icons/ag-icons.ts`.
- The prototype `<style>` block is copied verbatim into `web/src/styles/app.css`.
